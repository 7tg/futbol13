# FUTBOL13 launcher

The source of the `eboot.bin` in FUTBOL13's PS5 app, PPSA99405: built as PES 2013's own app
(`GAME=PPSA99405`), it shows one page to install PES 2013 from your own copy and set it up,
then hands over to prospero-win's runner, `game.bin`, in the same app folder. PES 2013's
install plan, `assets/plans/PES2013.json`, is generated by `profile/pes2013/make-pes2013-plan.py`
in the main repo.

The page is in Turkish on a console set to Turkish, English on any other: every sentence it
shows goes through `src/core/i18n.hpp`, and `src/core/i18n_strings.cpp` has its Turkish.
`tools/check-i18n.py` (run by `tools/store-test.sh`) fails when a sentence has no row. The
fonts in `assets/fonts` are baked with Latin-1 and Latin Extended-A for it.

## Building

The main repo's `tools/build.sh` builds it, in its `game-app` step. The quick host tests here
run with `bash tools/store-test.sh`.
